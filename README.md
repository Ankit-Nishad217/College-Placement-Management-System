# College Placement Management System

A simple College Placement Management System developed using Node.js, Express.js, and Handlebars.

## Implementations

### 1. HTTP Module
Uses Node.js built-in HTTP module with manual routing and request-response handling.

### 2. Express.js + Handlebars
Uses Express.js for routing and Handlebars for dynamic HTML pages.

## Features

- Placement home page
- Company listing
- Company details
- Student listing
- Student details
- Job listings
- Dynamic routes
- Handlebars `each` loop
- Handlebars conditional rendering
- CSS styling

## Technologies Used

- Node.js
- Express.js
- Handlebars
- HTML
- CSS
